# 🎓 Student Attendance & Academic Performance Dashboard

## 📊 Overview
Power BI dashboard analyzing student attendance,
mathematics and reading scores, and academic performance
distribution across cities, gender, and education levels
in Uzbekistan.

## 🛠️ Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Excel / CSV data source

## 📌 Key Metrics
- Average Attendance: 90.26%
- Average Math Score: 74.10
- Average Reading Score: 76.35
- Average Age: 9.32

## 📈 Dashboard Features
- Student count by city and gender (grouped bar chart)
- Math vs Reading score comparison by city (line chart)
- Attendance rate by education level (donut chart)
- Average age by education level (horizontal bar chart)
